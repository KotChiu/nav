# MotoNav 2.1 — Carbon Racing UI / 配色修订

> 设计分支 `codex/visual-system-redesign-20261110`，基于 `feature/board-2.1` 精确提交 `b3cc3ad8dfb5591e5da8d604049e45ea272721ee`。本改造限于 **2.1 英寸 ST7701S RGB / 480×480 圆屏**，不覆盖原分支的新地图地点标注、滑动优化、手机侧协议或电子吧唧图片传输。当前为 Draft PR #4，**没有通过真实硬件视觉验收**。

## 视觉原则

- **不要像素手表、卡通表情包或赛博霓虹拼贴。** 采用「Carbon Racing / 石墨竞速」：去掉上一版蓝绿色系。整体采用石墨近黑底、石墨灰卡片、暖白正文，少量竞速橙用在选中/进度/主要操作，冰蓝专用于手机连接与天气数据。导航警示仍保留红色语义色。
- **只有一个排版字族：LVGL Montserrat。** 16 / 20 / 24 / 28 / 40 / 48 px 六级；大号 48 px 实时时间或速度。取消 `WatchDigits.c` 像素字体在实际界面的引用。
- **真实信息优先于装饰。** 首页时钟、连接状态、当前温度与天气；天气页当前状况+四格预报；Ride 页真实车速/路程进度；Music 读取手机媒体信息；股票读取真实行情；电子吧唧继续从手机上传图片。
- **圆形安全区域。** 466×466 逻辑坐标，实体显示为 480×480，重要文案和可点控件均位于圆周内，绝不用右下角常规矩形底部导航栏。
- **保护驾驶信息。** 路线、转向、车道、红绿灯和地图仍按原可靠逻辑；靠近路口自动从非导航页回到导航页，视觉修改不改变 BLE 协议和导航数值。

## 每一页具体变化

| 页面 | 视觉和内容 | 真实状态来源 |
|---|---|---|
| Home | 无像素字符的 48px 时间、细线双环、连接状态胶囊、温度与天气卡、简洁滑动提示 | 手机时间同步、BLE、天气、设备电池 |
| Weather | 48px 大温度和天气状态、四个有层次的预报位置；天气详情走原手机中文 bitmap 图层 | 和风天气 / 手机 App 传入的 `#W` 数据 |
| Music | 统一无衬线标题、唱片封面、三个大触摸音乐控制、清晰播放状态 | 手机封面、媒体控制状态、HID |
| Ride（原 Companion） | **完全不再显示表情包**；圆形进度环、车速和连接状态，拥有仪式感但没有虚构状态 | 设备实时导航、行程进度、车速 |
| Markets | 标题和卡片改成统一蓝灰，行情涨跌语义色保留 | 手机推送行情、中文股票名 bitmap |
| Settings | **独立的四分类交互控制中心**，不再只放一个亮度滑杆 | 当前设备设置 / Preferences |
| Badge | 有图片时保持手机上传原图占满圆屏；没有图片时显示简洁的 LVGL 空状态 | 手机图片上传协议（未改动） |

## Settings：实际交互，不是假按钮

| 分类 | 项目 | 触发与状态 |
|---|---|---|
| Display | Brightness | 滑杆 5–180，立即控制背光，松手后延迟写入 `bright` |
| Display | Orientation | 每次点击 **顺时针 +90°**；与现有屏幕转向矩阵共享，已有延迟持久化到 `rotd` 与 `rot` |
| Ride | Minimal map | 切换 `cleanOn`，重绘地图，持久化键 `cleanmap`；手机后续指令可能覆盖本地偏好 |
| Ride | Trip ring | 切换 `progOn`，重绘导航，持久化键 `progring`；手机后续指令可能覆盖本地偏好 |
| Link | Music keys | `HID` 与 `APP` 真实两种模式，执行原有 `#HM` 同款状态清理与持久化到 `mediahid`；手机端模式仍需匹配 |
| Link | Phone status | BLE 已通过认证/等待配对的真实状态 |
| About | Device name / Firmware / PSRAM | 只读，显示真实蓝牙名、固件版本和空闲 PSRAM |

设置页的显示根对象和事件回调集中在 `ui/LvglSettingsPanel.h`；主页/天气/Ride 分别对应独立 LVGL 组件。所有页面按原来的 `PageRoutes.h` 滑动顺序，不篡改触摸算法和旧版路线缓冲。

## 已有兼容性边界

- 导航 **速度/距离/路名/车道/道路覆盖**仍有 Arduino GFX 和手机 4bit 灰度图的绘制历史，避免随意替换安全敏感的地图文字。代码只有把「通用仪表页的本地文字」统一成 Montserrat，并没有谎称所有手机渲染的中文都是 Montserrat。
- 电子吧唧继续保持 232×232 RGB565 图像的原始传输与 2× 展示方式；未做会破坏颜色的有损转换。
- 不合并旧的 LVGL 迁移 PR #2，也不覆写 2.1 功能分支。后续可另行解决两个 PR 的合并冲突。
- 暂未进行真机烧录、外部手机数据实测、0°/90°/314° 触摸坐标对齐、PSRAM 峰值和实体圆屏文字锯齿对比。这些必须在硬件验收后才能签署通过。

## 软件准出

```bash
# 无设备编译，验证 Arduino Core 3.3.10 + LVGL 8.3.10
python3 firmware/build.py --board 21 --jobs 2

# 外观与真实设置功能结构静态验收
python3 tools/ui-audit.py
g++ -std=c++17 -O2 firmware/tests/PageRoutesTest.cpp -o /tmp/motonav-route && /tmp/motonav-route
```

**回滚**：PR 不合并即可，原 `feature/board-2.1` 的 `b3cc3ad` 及历史提交完整保留。
