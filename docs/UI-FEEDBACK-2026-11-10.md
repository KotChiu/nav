## 修改

- `VisualLanguage.h` / `DeviceContext.h`：页面背景统一 RGB #000000，卡片保留较浅表面色。
- `HomeStackMotion.h` / `LvglOverlay.h`：首页底部两块改为纵向叠放的完整卡片，入口为设置与股票；保留上下拖动展开与左右切页。
- `LvglOverlay.h`：每只股票一张实际卡片，纵向滚动，保留中文名称位图、报价、涨跌幅和已有 K 线；删除假卡背、NEXT POSITION 与上一只/下一只按钮。
- `LvglSettingsPanel.h`：设置分类为文字标签，点击定位真实卡片列表；列表可上下滚动。旋转为 0–359° 滑杆，松手后应用并沿用延迟保存，防止坐标系在拖动时改变。亮度沿用原有控制与持久化。
- `PageRoutes.h`：从正常切页顺序移除骑行页。页面 ID 未重编号。
- `PageNavigation.h` / `LvglOverlay.h`：歌名、歌手、歌词限制在独立区域，在 LVGL 重绘后补绘手机位图；有封面时可显示歌词。音乐按钮去掉默认内边距。删除音乐和设置的下滑回家提示。
- 股票/设置纵向手势交给列表，横向仍用于切页；没有改变天气原有点击查看详情的交互。
